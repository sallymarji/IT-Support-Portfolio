# Computer Troubleshooting

## Problem 1: Computer Is Running Slowly

Possible Causes:
- Too many programs running.
- Not enough RAM.
- Low storage space.

Possible Solutions:
- Close unnecessary programs.
- Restart the computer.
- Check available storage.
- Disable unnecessary startup applications.

## Problem 2: No Internet Connection

Possible Causes:
- Wi-Fi is disabled.
- Router problem.
- Incorrect network settings.

Possible Solutions:
- Check Wi-Fi connection.
- Restart the router.
- Run Windows Network Troubleshooter.

  ## Problem 3: Printer Is Not Printing

Possible Causes:
- Printer is offline.
- Paper jam.
- Low ink or toner.
- Incorrect printer settings.

Possible Solutions:
- Check the printer connection.
- Remove jammed paper.
- Check ink or toner levels.
- Restart the printer.


  
## Problem 4: Computer Won't Turn On

### Possible Causes
- Power cable is disconnected.
- Power outlet is not working.
- Power supply failure.
- Laptop battery is empty.

### Troubleshooting Steps
1. Check the power cable.
2. Test the electrical outlet.
3. Check the power adapter.
4. Check the laptop battery.
5. Contact a technician if the problem continues.

### Important
Always disconnect power before inspecting internal hardware.
